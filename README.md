# 🥕 Bobo Adventure｜五月天卜卜大冒险

一个简单可爱的横版像素闯关小游戏。

Bobo（卜卜）这一次离开了桌面，开始了一场小小的冒险。

操控卜卜一路向前，躲避障碍、收集金币，最终抵达终点！

**无需安装，无需下载，无需额外环境。**

打开网页即可直接游玩。

支持电脑浏览器运行，可直接部署到 GitHub Pages。

---

## ✨ Features

### 🎮 简单易玩的横版闯关

经典的横版平台跳跃玩法：

* 左右移动
* 跳跃
* 躲避障碍
* 收集金币
* 抵达终点
* 3 条生命

游戏整体保持轻量简单，大部分玩家都可以顺利完成。

### 🪙 收集金币

冒险过程中可以收集金币。

在躲避障碍的同时，也可以尝试收集更多金币，看看自己最终能拿到多少。

### 🚩 最终目标

每一关都有一个明确的终点。

一路向前，抵达红色终点旗帜。

完成最后一关后，卜卜会迎来属于自己的**通关欢呼动画** 🎉

---

## 🕹️ 游戏操作

| 操作   | 按键        |
| ---- | --------- |
| 向左移动 | `←` / `A` |
| 向右移动 | `→` / `D` |
| 跳跃   | `Space`   |
| 暂停   | `P`       |
| 重新开始 | `R`       |

也可以直接使用键盘方向键进行游戏。

---

## 🚀 开始游戏

### 方法一：在线游玩

如果项目已经部署到 GitHub Pages，可以直接访问玩游戏：https://yiyuanczen.github.io/bobo-adventure/

无需安装任何软件。

### 方法二：本地运行

下载项目后，直接打开：

```text
index.html
```

即可运行游戏。

不需要：

* Node.js
* npm
* React
* Vue
* Phaser
* 后端服务
* 数据库

这是一个完全由 **HTML + CSS + JavaScript + Canvas** 构成的纯前端小游戏。

---

## 🎨 游戏画面

游戏采用复古 **8-bit / Pixel Art** 像素风格。

整体希望保持一种：

**简单、可爱、有一点复古游戏感的卜卜冒险世界。**
